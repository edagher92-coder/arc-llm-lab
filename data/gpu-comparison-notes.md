# GPU comparison: method and sources

- **Specs** (VRAM, memory bandwidth) are vendor specifications. Rows cite their source in the `spec_source` column: the TechPowerUp GPU database (https://www.techpowerup.com/gpu-specs/) for most, and for the Arc B570, Arc Pro B50 and Arc Pro B70 (added 2026-10-10) the pages named in the CSV, because they were checked there. These are secondary sources, so check Intel's own spec page before you buy.
- **Prices** are Australian street prices from the linked trackers on the given dates. Blank means no reliable AUD source was found, so none is shown rather than guessed.
- **Fits 27B Q4 + 32K context:** Qwen3.8-27B UD-Q4_K_M weights 16.46 GB, plus the DFlash2 drafter and buffers (17.15 GiB measured), plus 2.0 GiB f16 KV for 32K, plus at least 1.1 GiB headroom, comes to about 21 GB of VRAM.
- **Theoretical decode ceiling = memory bandwidth / 16.46 GB.** Without speculative decoding, a dense model must stream every weight once per generated token, so this is an upper bound that real systems reach 50-80% of. It is an estimate, not a measurement, for every card except the B60.
- **B60 measured:** 16.0 tok/s without a drafter (58% of its ceiling, data/raw/compare-f16.txt); 42.3 tok/s eval-suite throughput with the DFlash2 drafter (wall-clock, prompt processing included; per-request decode 47-58 tok/s; data/raw/tune.txt). Speculative decoding verifies several drafted tokens per pass over the weights, which is how it exceeds the no-drafter ceiling. Other cards would gain from it too.
- **Arc Pro B70 (32GB, 608 GB/s):** the ceiling of 36.9 tok/s is the same estimate (608 / 16.46), not a measurement, and no AUD price is shown because no dated source was recorded. The Arc B570 (10GB) and Arc Pro B50 (16GB) cannot hold this 27B model plus a working context, so no ceiling is given for them.
