## Additional defects found
11. **Impossible display fix:** docs §2.4 says to move the monitors to the CPU iGPU / set BIOS Primary Display = iGPU. **The Ryzen 7 3700X has no iGPU**, so this cannot be done on this machine.
12. **Clock/voltage advice:** docs §2.5 recommends a +100-150 MHz V-F offset and power-limit changes. That violates the no-clock/voltage rule. Not acceptable as a default.
13. **"Hidden IQ" diagnosis doesn't apply:** the user's GGUF header has 0 IQ/Q2_K/Q3_K tensors. The repack script's advice (`llama-quantize --pure --token-embedding-type q4_k`) is a weight change and is **not lossless**. It also suggests downloading a third-party checkpoint. The XMX "dpas.8x8 linear INT" claims are unsourced, and the Vulkan path dequantises in shaders anyway.
14. **The #30503 framing misses the install's real FA path:** with f16 KV, PR #29357's Xe FA shaders (advertised 8x16x16) already handle prefill and verify. The patch would mainly affect q8_0 K/V FA (draft context / future q8_0 main KV). Its expected decode gain is not established.
15. **Unverified numbers presented as "verified":** "53.3 mean per-req", "0.788 acceptance", "16/16 tasks 60.5 s", "dwm 2.6-3.3 GB" and the "52.7 → 22.2 contention drop" (references a `gpu-contention-20261017.csv` not in the pack). Several Reddit thread IDs and blog figures could not be checked here (community, unverified).
16. **Unsafe patch-application idempotency:** the patcher treats any file containing the string "Issue #30503" as already patched (L31). A comment would make it skip.
17. **Task 2 encourages raising ctx to 96K** on the basis of the 2.17 GiB weight saving. That equates checkpoint savings with usable context, and the context math above shows 96K f16 still doesn't fit.
