Which Intel Arc card, and which model fits?

Only the Arc Pro B60 row is measured. The rest are specifications and arithmetic: “fits” is an ESTIMATE for a 16.46 GB Qwen3.8-27B Q4_K_M weights file plus its drafter, buffers and a 32K f16 KV cache (about 2 GiB), roughly 21 GB in all. Rule of thumb for other models: the GGUF file should be no larger than your VRAM minus about 3 GiB.
