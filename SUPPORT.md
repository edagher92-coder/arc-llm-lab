# Support

Where to go, depending on what you need:

- **Set-up help, or "is this normal?"**: start in [Discussions](https://github.com/edagher92-coder/arc-llm-lab/discussions). The [FAQ](docs/FAQ.md) covers Vulkan or SYCL, Ollama and LM Studio, context limits and agent safety.
- **Something in this repo is broken** (a script, build step, doc or checker): [report a bug](https://github.com/edagher92-coder/arc-llm-lab/issues/new?template=bug.yml) with the exact commands and output.
- **Benchmark numbers from your card**: [benchmark result form](https://github.com/edagher92-coder/arc-llm-lab/issues/new?template=benchmark.yml). Attach the raw `llama-bench` output.
- **Show your setup**: [Show and tell](https://github.com/edagher92-coder/arc-llm-lab/discussions/categories/show-and-tell).

Never post API keys, tailnet names or other private details in an issue or discussion.
